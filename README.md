# Meu personal

Leia `README-CLOUDFLARE.md` para configurar o projeto com Cloudflare D1 e Workers.

A interface inicial original está em `public/index.html`; a página pública de planos está em `public/comprar.html`.
O app usa a URL da API definida em `public/js/api-config.js`; veja no guia Cloudflare as instruções para testar com Capacitor e o estado dos dados remotos.
O app está publicado como web app em `https://falling-art-9ea8.frcmxpx.workers.dev`; o favicon MP está em `public/favicon.svg`.
